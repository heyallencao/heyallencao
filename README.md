## front door

If you found this page, you are not looking at a polished profile card.

You are stepping into a workshop.

I build personal systems for humans and AI:

- workflows that hold up under ambiguity
- agents that feel usable instead of theatrical
- memory systems that stay operational
- interfaces that make complex tools easier to enter

## on the workbench

- **[PrimeFlow](https://github.com/heyallencao/PrimeFlow)**  
  a workflow kernel for moving work from vague to executable

- **[NoonFlow](https://github.com/heyallencao/NoonFlow)**  
  a visual AI coding workspace for multi-runtime collaboration

- **AI Working System**  
  my live environment for rules, content, code, memory, and agent behavior

## pinned to the wall

Things I keep coming back to:

- structure before noise
- systems that stay readable as they grow
- tools with personality, not just utility
- serious building without generic surfaces
